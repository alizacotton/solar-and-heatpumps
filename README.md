# solar-and-heatpumps
This is a program designed to gather data on solar and heat pump feasability for residents of a certain geographic area.

You will need to edit the file env.py in order to configure your environment and run the program successfully. 

Once you have edited env.py, you can run main.py to generate your data. 

#how is this useful?
Heatpumps are electrical heating systems that can be much more sustainable than oil or gas if powered by cleanly generated electricity. When installed on their own, heat pumps tend to only increase a resident's electrical bill. When installed with rooftop solar, heatpumps become much more economically feasible because a resident is generating their own electricity instead of having to pay for grid electricity. Further, a heatpump often ensures that solar panels are not generating an excess of electricity, which is complicated to store or feed back into a grid. 

This program allows towns to generate reasonable quotes on power capacity and needs as well as estimated costs and financing options for installing both a heatpump and rooftop solar. This program uses the Google Solar API and the calculator on heatpumpshooray.com.
